# Uulzwar_zai

Уулзварын зай хэмжилт — төмөр замын зам төмрүүдийн уулзварын зайг хэмждэг вэб апп (PWA).

## Юу хийдэг вэ

- Утсанд суудаг, **офлайн ажилладаг** апп (нүүр дэлгэцэнд нэмнэ).
- Дугуй эргүүлж хэмжилтээ хурдан оруулна, аюултай хэмжээнд анхааруулга өгнө.
- ПД-1 … ПД-13 замын хэсгүүдийн ажилчид өөрийн хаягаар нэвтэрнэ.
- Ажилтан хэмжилтээ **☁️ илгээхэд** тухайн хэсгийн админ бүх ажилчны өгөгдлийг
  **нэг Excel хүснэгтэд** нэгтгэж татна.

2. Гарсан линкийг утсаараа нээнэ:

   - **iPhone (Safari)**: Share ⤴ → *Add to Home Screen*

## Нэвтрэлт

Firebase төсөл (`uulzwar-zai`) холбогдсон. Console дээрх үлдсэн тохиргоог
[`FIREBASE-SETUP.md`](./FIREBASE-SETUP.md)-аас үзнэ үү (3–7-р алхам).

Хэсэг бүрт **2 хаяг**: админ + ажилтан. Ажилтны хаягийг тухайн хэсгийн бүх
ажилчид хуваалцан хэрэглэнэ (зэрэг нэвтэрч болно), апп дээр өөрийн нэрээ
бичснээр Excel дээр хэн юу хэмжсэн нь ялгарна.

| Үүрэг | Боломж |
|---|---|
| **Ажилтан** | Хэмжилтээ хийж, өөрийн ПД рүү илгээнэ |
| **Админ** | Өөрийн ПД-ийн бүх өгөгдлийг харж, нэг Excel болгож татна |

ПД хоорондын тусгаарлалт нь серверийн дүрмээр хийгдсэн — ПД-6-гийн админ
ПД-7-гийн өгөгдөлд хүрэх боломжгүй.

## Хадгалах хугацаа

Илгээсэн өгөгдөл **30 хоног** хадгалагдаад Firestore-ийн TTL бодлогоор
автоматаар устана. Утсан дээрх дотоод санах ой ч мөн адил цэвэрлэгддэг.
Админ Excel-ээ сар бүр татаж хадгалж байхыг зөвлөе.
