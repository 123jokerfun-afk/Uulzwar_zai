# Uulzwar_zai

Уулзварын зай хэмжилт — төмөр замын зам төмрүүдийн уулзварын зайг хэмждэг вэб апп (PWA).

## Юу хийдэг вэ

- Утсанд суудаг, **офлайн ажилладаг** апп (нүүр дэлгэцэнд нэмнэ).
- Дугуй эргүүлж хэмжилтээ хурдан оруулна, аюултай хэмжээнд анхааруулга өгнө.
- ПД-1 … ПД-13 замын хэсгүүдийн ажилчид өөрийн хаягаар нэвтэрнэ.
- Ажилтан хэмжилтээ **☁️ илгээхэд** тухайн хэсгийн админ бүх ажилчны өгөгдлийг
  **нэг Excel хүснэгтэд** нэгтгэж татна.
- Утсанд **хадгалагдсан хуучин хэмжилтийг** ч дараа нь үүл рүү (админ руу)
  илгээж болно — «📂 Өмнөх хэмжилтүүд» хэсгээс.
- Утасны **ухрах товч** нээлттэй цонхыг хаадаг — аппаас санамсаргүй гарахгүй.

## Нэвтрэлт

Firebase төсөл (`uulzwar-zai`) холбогдсон. Console дээрх үлдсэн тохиргоог
[`FIREBASE-SETUP.md`](./FIREBASE-SETUP.md)-аас үзнэ үү (3–7-р алхам).

Хэсэг бүрт **2 хаяг**: админ + ажилтан. Ажилтны хаягийг тухайн хэсгийн бүх
ажилчид хуваалцан хэрэглэнэ (зэрэг нэвтэрч болно), апп дээр өөрийн нэрээ
бичснээр Excel дээр хэн юу хэмжсэн нь ялгарна.

| Үүрэг | Боломж |
|---|---|
| **Ажилтан** | Хэмжилтээ хийж, өөрийн ПД рүү илгээнэ |
| **Админ** | Өөрийн ПД-ийн бүх өгөгдлийг харж, нэг Excel болгож татна |

### Хадгалсан өгөгдлөө илгээх

Хэмжилт бүр эхлээд **утсанд хадгалагдана** (сүлжээгүй ч ажиллана). Дараа нь:

| Хаанаас | Юу хийх вэ |
|---|---|
| «📂 Өмнөх хэмжилтүүд» → мөр бүрийн **☁️** товч | Тухайн нэг хэмжилтийг илгээнэ |
| «📂 Өмнөх хэмжилтүүд» → **☁️ Илгээгээгүй N хэмжилтийг илгээх** | Илгээгээгүй бүгдийг нэг дор илгээнэ |
| Мөрөн дээр **удаан дарж** гарах цэс | Илгээх · харах · Excel/CSV татах · устгах |
| Хэмжилтээ нээгээд доод талын **☁️ Админ руу илгээх** | Тухайн хэмжилтийг илгээх/дахин илгээх |

### Огноо сонгож нэг Excel болгох

**«📊 Огноо сонгож нэг хүснэгтээр татах»** дарахад хэмжилтүүд **огноогоороо**
жагсаж гарна — өдөр бүрийн хажууд хэдэн хэмжилт, аль зам, хэн хэмжсэн нь
харагдана. Хэрэгтэй өдрүүдээ тэмдэглээд **«📊 Нэгтгэж татах»** дарна:

- Сонгосон бүх өдрийн өгөгдөл **нэг хүснэгтэд** нийлнэ (мөр = км × чиглэл,
  багана = үений дугаар). «Огноо» багананд аль өдрийнх нь бичигдэнэ.
- Анхдагчаар бүх өдөр сонгогдсон байна; **«Бүгдийг сонгох»** /
  **«Сонголт цуцлах»** товчоор хурдан солино.
- Файлын нэрэнд сонгосон хугацаа орно, ж нь
  `нэгдсэн_ПД6_уулзвар_2026-08-10_2026-08-12.xlsx`.
- Админ нэвтэрсэн бол хэсгийн бүх ажилчны ирсэн өгөгдлөөс, ажилтан бол
  өөрийн утсанд хадгалагдсанаас сонгоно.

### 🔧 Уулзварын зай тохируулах

Хэмжсэн зайг **жигдрүүлэхэд аль үеийг хаашаа хэдэн мм зөөхийг** бодож өгнө.
Тохируулгын дэлгэцээс **«🔧 Уулзварын зай тохируулах»** → хэмжилттэй км-үүд
гарна → нэг км-ийн **Баруун** эсвэл **Зүүн** талыг дарна.

**Байвал зохих зай** = тухайн км-ийн нэг талын *нийт зай ÷ үений тоо*. Нийт зай
өөрчлөгдөхгүй — зөвхөн жигд тарна.

Хүснэгт нь үе тус бүрээр:

| Багана | Утга |
|---|---|
| Үе | үений дугаар |
| Хэмжсэн | хэмжсэн зай |
| Байвал зохих | *үе × дундаж* (жишээ нь дундаж 4 бол 1-р үе 4, 2-р үе 8 … 40-р үе 160 мм) |
| Шилжүүлэх | тухайн үений араах төмрийг **→ урагш** / **← хойш** хэдэн мм зөөх |

Дээр талд нь дүгнэлт: нэг зүг рүү зөөгдөх **дараалсан үеүүдийг бүлэглэн**
«1–2 үе → урагш», «3–5 үе ← хойш» гэх мэтээр өөр өөр өнгөөр ялгаж, хамгийн их
шилжилтийг нь харуулна.

**Тооцох арга.** Үеийг дундажид хүргэхэд араас нь орох төмөр зөөгдөж дараагийн
үений зай мөн хэмжээгээр өөрчлөгддөг. Тиймээс хуримтлалаар бодно:

```
шилжүүлэлт(n) = n × дундаж − (1..n үений зайн нийлбэр)
```

Жишээ — 2, 5, 6 (дундаж 4): 1-р үе +2 мм (1-р үе 4 болж, 2-р үе 3 болно),
2-р үе +1 мм (2-р үе 4 болж, 3-р үе 5 болно), 3-р үе −1 мм … Сүүлийн үед
шилжүүлэлт 0 болж нийт зай хэвээрээ үлдэнэ.

**Ажиллах дараалал.** Уулзварын зай 0-оос бага байж чадахгүй. Эхний үеэс
дараалуулахад хаа нэгтээ зай хүрэхгүй болвол апп үүнийг илрүүлж «⚠️ N-р үеэс
урвуугаар ←» гэж сануулна.

Админ нэвтэрсэн бол хэсгийн бүх ажилчны ирсэн өгөгдлөөс, ажилтан бол өөрийн
утсанд хадгалагдсанаас км-ээ сонгоно.

### Нэвтрэлт нэг л удаа

Нэг удаа нэвтэрсний дараа апп нээх бүрд **нэвтрэх дэлгэц гарахаа болино** —
шууд ажлын дэлгэц гарч, өмнөх хаягаараа үргэлжилнэ. Нэвтрэх дэлгэц зөвхөн:

- анх удаа (эсвэл огт нэвтрээгүй) нээхэд,
- **«Гарах»** дарсны дараа гарна.

ПД, эрх, нэрийг утсанд хадгалдаг тул **сүлжээгүй үед** апп нээхэд ч өмнөх
хаягаараа шууд ажиллана. Өмнө нь сүлжээ муутай үед бүртгэл шалгаж чадалгүй
хэрэглэгчийг гаргачихдаг байсныг зассан — сүлжээний алдаанд хэрэглэгчийг
хэзээ ч гаргахгүй, зөвхөн серверээс «эрх байхгүй/хаагдсан» гэж хариулсан үед л
гаргана.

### Ухрах товч

Утасны ухрах товч (Android-ын ← эсвэл захаас гулсуулах) нь аппаас гарах биш,
**нээлттэй цонхыг хаана** — цонхнууд нээгдсэн дарааллаараа буцаж хаагдана.

| Хаана байхад | Ухрахад |
|---|---|
| Ямар нэг цонх нээлттэй | Хамгийн дээд цонх хаагдана |
| Хэмжилт хийж байхад | «Хэмжилт дууссан уу?» асууж, тохируулга руу буцна |
| Тохируулга / нэвтрэх дэлгэц | Урьдын адил аппаас гарна |

Тохируулгын дэлгэцийн доод талд **хувилбарын дугаар** бичигдэнэ. Шинэчлэлт
утсанд хүрсэн эсэхийг эндээс шалгана — дугаар нь хуучин байвал аппаа хаагаад
дахин нээх (эсвэл хөтчөөр нээж refresh хийх) хэрэгтэй.

### Хэмжилт устгах

Жагсаалтын мөрөн дээр **удаан дарахад** (0.5 сек) сонголтын цэс гарна:
**☁️ илгээх · 👁 харах · 📊 Excel · 📄 CSV · 🗑 устгах**. Устгахыг сонгоход
«Устгах уу?» гэж баталгаажуулж, зөвшөөрсөн үед л устгана — илгээгээгүй
хэмжилт бол тэрийг нь тусад нь сануулна. Санамсаргүй дарж устгахаас
сэргийлж жагсаалтаас хогийн савны товчийг авсан.

Мөр бүр дээр **☁️ илгээсэн** / **илгээгээгүй** гэсэн тэмдэг гарна. Илгээснийхээ
дараа шинэ хэмжилт нэмбэл дахин «илгээгээгүй» болж, дахин илгээхийг сануулна.
Сүлжээгүй үед дарвал өгөгдөл дараалалд орж, интернэт орсны дараа автоматаар
илгээгдэнэ.

ПД хоорондын тусгаарлалт нь серверийн дүрмээр хийгдсэн — ПД-6-гийн админ
ПД-7-гийн өгөгдөлд хүрэх боломжгүй.

## Хадгалах хугацаа

Илгээсэн өгөгдөл **30 хоног** хадгалагдаад Firestore-ийн TTL бодлогоор
автоматаар устана. Утсан дээрх дотоод санах ой ч мөн адил цэвэрлэгддэг.
Админ Excel-ээ сар бүр татаж хадгалж байхыг зөвлөе.
