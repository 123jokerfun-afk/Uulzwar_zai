# Uulzwar_zai

Уулзварын зай хэмжилт — төмөр замын зам төмрүүдийн уулзварын зайг хэмждэг вэб апп (PWA).

## Юу хийдэг вэ

- Утсанд суудаг, **офлайн ажилладаг** апп (нүүр дэлгэцэнд нэмнэ).
- Дугуй эргүүлж хэмжилтээ хурдан оруулна, аюултай хэмжээнд анхааруулга өгнө.
- ПД-1 … ПД-13 замын хэсгүүдийн ажилчид өөрийн хаягаар нэвтэрнэ.
- Ажилтан хэмжилтээ **☁️ илгээхэд** тухайн хэсгийн админ бүх ажилчны өгөгдлийг
  **нэг Excel хүснэгтэд** нэгтгэж татна.

## Файлууд

| Файл | Тайлбар |
|---|---|
| `index.html` | Апп бүхэлдээ (нэг файл) |
| `firestore.rules` | Firebase аюулгүй байдлын дүрэм — Console-д хуулж тавина |
| `FIREBASE-SETUP.md` | Нэвтрэлт тохируулах алхам алхмын заавар |

## Суулгах

1. GitHub → **Settings → Pages → Branch: `main` / `(root)` → Save**.
2. Гарсан линкийг утсаараа нээнэ:
   - **Android (Chrome)**: доор гарах «Суулгах» товч, эсвэл ⋮ → *Add to Home screen*
   - **iPhone (Safari)**: Share ⤴ → *Add to Home Screen*

## Нэвтрэлт асаах

Эхлээд апп **офлайн горимд** ажиллана — нэвтрэх шаардлагагүй, өгөгдөл утсанд
хадгалагдаж, Messenger-ээр дамжина.

13 хэсгийн ажилчид хаягаараа нэвтэрч, өгөгдөл автоматаар нэг дор цугларахыг
хүсвэл [`FIREBASE-SETUP.md`](./FIREBASE-SETUP.md)-г дагана (20–30 минут).

## Эрхийн зохион байгуулалт

| Үүрэг | Боломж |
|---|---|
| **Ажилтан** | Өөрийн хэмжилтээ хийж, өөрийн ПД рүү илгээнэ |
| **Админ** | Өөрийн ПД-ийн бүх ажилчны өгөгдлийг харж, нэг Excel болгож татна |

ПД хоорондын тусгаарлалт нь серверийн дүрмээр хийгдсэн — ПД-6-гийн админ
ПД-7-гийн өгөгдөлд хүрэх боломжгүй.
